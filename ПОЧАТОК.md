# Як продовжити роботу в Claude Code

У цій папці є все, щоб Claude Code одразу зрозумів задачу:

- `CLAUDE.md` — опис задачі, план і все, що ми вже з'ясували. Claude Code читає цей файл
  автоматично, коли ви відкриваєте папку.
- `samples/zrazky.pdf` — ваші три зразки заяв.

Для Claude Code потрібен платний план Claude (Pro, Max, Team або Enterprise).
Безкоштовний план його не включає.

## Варіант 1. Без терміналу (найпростіший)

1. Розпакуйте архів, наприклад у папку «Документи».
2. Встановіть застосунок Claude для комп'ютера: https://claude.com/download
3. Відкрийте застосунок і перейдіть на вкладку **Code**.
4. Виберіть розпаковану папку `esud`.
5. Напишіть перше повідомлення (текст нижче).

## Варіант 2. Через термінал

1. Розпакуйте архів.
2. Встановіть Claude Code.
   - **Windows:** відкрийте PowerShell і виконайте:
     ```
     irm https://claude.ai/install.ps1 | iex
     ```
   - **Mac:** відкрийте «Термінал» і виконайте:
     ```
     curl -fsSL https://claude.ai/install.sh | bash
     ```
3. Закрийте термінал і відкрийте його знову.
4. Перейдіть у папку проєкту, наприклад:
   ```
   cd Documents/esud
   ```
5. Запустіть Claude Code:
   ```
   claude
   ```
   Під час першого запуску відкриється браузер, щоб увійти у ваш акаунт Claude.

## Перше повідомлення для Claude Code

> Прочитай CLAUDE.md. У мене [Windows / Mac]. Почни з кроку 1: зроби читач заяв
> і перевір його на samples/zrazky.pdf. Покажи мені результат таблицею.
> Потім дай покрокову інструкцію, що встановити.

Далі просто йдіть за планом у CLAUDE.md. Якщо щось не працює, вставляйте Claude Code
текст помилки або скріншот.
