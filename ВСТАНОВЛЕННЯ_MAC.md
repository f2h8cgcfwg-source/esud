# Встановлення на Mac

Це потрібно зробити **один раз**. Займе приблизно 15 хвилин, більшість часу — очікування.

## 1. Завантажте проєкт із GitHub

1. Відкрийте https://github.com/f2h8cgcfwg-source/esud (увійдіть у GitHub, якщо попросить).
2. Натисніть зелену кнопку **Code** → **Download ZIP**.
3. Двічі клацніть завантажений `esud-main.zip` у «Завантаженнях».
4. Перемістіть папку `esud-main` у «Документи». Назву можна не змінювати.

## 2. Встановіть Python

1. Відкрийте https://www.python.org/downloads/macos/
2. Знайдіть найновішу версію **Python 3.13** і завантажте «macOS 64-bit universal2 installer».
3. Відкрийте завантажений файл `.pkg` і натискайте «Продовжити» до кінця установки.

## 3. Запустіть установку програми

У папці `esud-main` двічі клацніть файл **`vstanovyty.command`**.

Відкриється вікно Терміналу, яке саме все встановить і наприкінці відкриє сторінку перевірки
трьох зразків. Просто чекайте, поки з'явиться «🎉 Готово!».

**Якщо Mac пише, що файл «неможливо відкрити, бо розробника не встановлено»:**
клацніть по файлу **правою кнопкою** (або з Ctrl) → **Відкрити** → у вікні ще раз **Відкрити**.
Це потрібно лише першого разу.

**Якщо подвійне клацання нічого не запускає:** відкрийте Термінал (Cmd + Пробіл → «Термінал»),
наберіть `bash ` (з пробілом наприкінці), перетягніть файл `vstanovyty.command` у вікно
Терміналу й натисніть Enter.

## Як перевірити власну заяву

Відкрийте Термінал і виконайте (шлях — до вашої папки):

```
cd ~/Documents/esud-main
source .venv/bin/activate
python chytach.py
```

Перед натисканням Enter після `python chytach.py ` (з пробілом) перетягніть файл заяви
мишкою у вікно Терміналу. Результат з'явиться в папці `rezultat`.

## Якщо щось пішло не так

Скопіюйте весь текст із вікна Терміналу (або зробіть знімок екрана: Cmd + Shift + 4)
і надішліть його Claude.
