# Встановлення на Mac

Це потрібно зробити **один раз**. Займе приблизно 15 хвилин.

## 1. Розпакуйте архів

Розпакуйте `esud.zip` у папку «Документи», двічі клацнувши по ньому. Має вийти папка
`Документи/esud`, а в ній файли `chytach.py`, `CLAUDE.md` і папка `samples`.

## 2. Встановіть Python

1. Відкрийте https://www.python.org/downloads/macos/
2. Знайдіть найновішу версію **Python 3.13** і завантажте «macOS 64-bit universal2 installer».
3. Відкрийте завантажений файл `.pkg` і натискайте «Продовжити» до кінця установки.

## 3. Відкрийте Термінал

Натисніть **Cmd + Пробіл**, наберіть `Термінал` (або `Terminal`) і натисніть Enter.
Відкриється вікно, куди вставляються команди. Кожну команду нижче копіюйте цілком,
вставляйте (Cmd + V) і натискайте Enter. Чекайте, поки команда завершиться, а потім вставляйте наступну.

Перевірте, що Python встановився:

```
python3 --version
```

Має з'явитися `Python 3.13…`. Якщо Mac запропонує встановити «інструменти розробника»
(command line developer tools), погодьтеся й дочекайтеся кінця установки.

## 4. Перейдіть у папку проєкту

```
cd ~/Documents/esud
```

Ця команда «заходить» у папку проєкту. Якщо ви розпакували архів в інше місце, наберіть
`cd ` (з пробілом наприкінці), перетягніть папку `esud` мишкою у вікно Терміналу й натисніть Enter.

## 5. Створіть окреме середовище для програми

```
python3 -m venv .venv
```

Створює всередині проєкту окрему «скриньку» для бібліотек, щоб вони не змішувалися з
іншими програмами на Mac. Нічого не виводить, і так має бути.

```
source .venv/bin/activate
```

Вмикає цю «скриньку». На початку рядка в Терміналі з'явиться `(.venv)`.

## 6. Встановіть бібліотеки

```
pip install -r requirements.txt
```

Завантажує бібліотеки для читання PDF і Word, а також Playwright для керування браузером.

```
playwright install chromium
```

Завантажує окремий браузер Chromium, з яким працюватиме програма (близько 150 МБ).
Ваш звичайний браузер вона не чіпає.

## 7. Перевірте читач заяв

```
python chytach.py samples/zrazky.pdf
```

Має з'явитися список із трьох заяв.

```
open rezultat/zrazky.html
```

Відкриває сторінку перевірки в браузері.

## Щоразу, коли повертаєтеся до роботи

Відкрийте Термінал і виконайте дві команди:

```
cd ~/Documents/esud
source .venv/bin/activate
```

Після цього можна запускати програму, наприклад: `python chytach.py "шлях до заяви.docx"`.
Шлях до файлу можна не набирати: перетягніть файл мишкою у вікно Терміналу.

## Якщо щось пішло не так

Скопіюйте весь текст із Терміналу (або зробіть знімок екрана: Cmd + Shift + 4) і надішліть його Claude.
